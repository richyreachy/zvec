# 阶段 81：固定候选域的查询留出验证

**本轮未通过预先冻结的三条件门槛，不在本协议内继续真实路径集成。** Hinge 码相对 native 的局部机器边界错误下降，但未优于在完全相同候选域重训的二阶矩对照。这是局部目标验证结果，不是新的 Recall/QPS 结果。

## 固定范围和验收规则

沿用先前只按访问元数据选定的 20 个中心、全部 640 条邻居码，以及 3072/1024 条数据库查询拆分（seed8101）。每条码只允许实际旋转残差绝对值最小的 16 维发生最多 2 次翻转，尺度上限为 51/50；137 是预算过滤前的候选组合上限。native、二阶矩和 hinge 使用相同候选域，零残差或无有效标签等退化情况按冻结规则回退，不另选中心或维度。

训练只读取训练分区，保存全部候选目标、选中索引、模型和冻结清单后，才运行一次验证评分。两个学习方法均在 621/640 条码上选择了非 native 候选。最优性范围仅限这些已枚举的受限候选和记录的 float64 目标，不是完整 768 维整数最优性。

主指标为固定 native 路径上、目标尚未展开的 proposal，相对其 native 桶两侧有限机器跃迁点的错误率。先在查询内对全部有效边界行平均，再对全部 1024 条验证查询等权。真实分数恰好落在跃迁点时，机器分类按右侧包含规则计入主指标；它只从 hinge 训练损失的分子排除，固定分母不变。已展开目标不计入主指标。

该指标判断相对 native 桶边界的位置，不是完整桶号正确率，也不是召回率。数据仍是同一数据库与图上的查询留出，评估状态来自旧 native 路径；不是外部查询盲测或实际新路径。

唯一进入小规模真实路径集成的门槛，是以下三项同时成立：hinge−native 的错误率差≤−0.5 个百分点；该差值的 95% bootstrap 区间上界<0；hinge−二阶矩的点估计≤0。第三项是点估计比较，不是统计非劣效检验。全部 4000 次重采样使用同一批配对 query 索引，PCG64 seed8103，分位数采用线性插值。

## 结果

验证完整覆盖 2183 个冻结状态、1024 条查询和 69856 个 lane；全部 native 分数通过逐 bit 核对。排除 1164 个已展开目标后，剩余 68692 个 proposal、137384 条主指标边界行。全部查询均有主指标支持。

| 方法 | 查询等权机器边界错误率 | 原始错误行数 |
|---|---:|---:|
| Native | 40.279538% | 55340 |
| 同候选域二阶矩 | 34.776607% | 47893 |
| 固定阈值 hinge | 35.072091% | 48287 |

| 配对差值 | 点估计（百分点） | 95% bootstrap 区间（百分点） |
|---|---:|---:|
| Hinge − Native | −5.207447 | [−5.425539, −4.991992] |
| Hinge − 二阶矩 | +0.295484 | [+0.156089, +0.431026] |

前两个条件通过，第三个条件未通过，故总门槛失败。没有据此修改 γ、预算、候选维度、中心名单、样本权重或验收阈值。

二阶矩对照在这一次留出中表现更好，为后续独立设计提供了观察性线索；它不能证明二阶矩普遍更优，也不能绕过本轮门槛直接启动真实路径集成。Hinge 和二阶矩相对 native 的改善，尚不说明新路径、Recall 或 QPS 会改善。

理想 hinge 使用实际中心距离锚定的常数 C，仍保持固定阈值的线性化。锚定后，二阶矩目标中的 δ·e 是另一个明确定义的代理，不应被描述成该锚定理想分数误差的精确 MSE。

## 校验和证据

独立桶跃迁校验只使用合成 entry/width，直接编译生产 `QuantizedGraphBucket`，并提取当时成功导出器的原跃迁函数，与独立的非负浮点位序二分实现比较。35 种合成输入覆盖全部 2047 个边界，共核对 45042 个有限跃迁和 26603 个不存在有限跃迁的边界，完成 360336 次右侧包含判定检查。另覆盖 140 次正负零/次正规数检查、72 次非法输入拒绝、12 种有限分数除法溢出，以及 3 例跃迁点为最大有限值、后继为正无穷的情形。

分析器先通过手算 fixture：真实 tie 保留、visited 排除、空 query 零贡献、query 等权区别于原始行等权，以及两组差值复用同一 bootstrap 索引。随后一次实际分析通过全部 139712 个边界的生产桶映射与右侧包含等价校验；原码自身负控制和精确分数正控制通过。

Bench 原始证据分别位于 `path81_validation_analysis_v1/`、`path81_analysis_selftest_v1/` 和 `path81_transition_checks_v1/`。源码、输入哈希、逐查询整数计数和 bootstrap 数值已保留。仓库中的原始结果副本、格式后重放及精确差异清单由 `results/stage39_analysis_archive_manifest.json` 和 `results/stage39_analysis_postformat_validation.json` 列明；原始成功文件不被格式化或覆盖。

另一套独立实现使用逐行整数计数和 Fraction 查询均值，1024 条查询的 ID、分母及三种方法的错误整数计数均与主分析一致；汇总均值约 2.7×10⁻¹⁵ 的差异来自 FP64 累加。审计者在实施前曾收到未请求的主结果摘要，随后没有读取主分析代码或逐查询结果再进行独立实现。因此这是独立代码与整数核算复核，不声称双盲。比较记录由 `results/path81_independent_metrics_comparison.json` 保存。
