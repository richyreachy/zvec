# 部分计算 RaBitQ 分数：无偏条件、可计算界及现有先例

结论：可以研究部分计算后的线性外推，但它增加了一层误差。完整 RaBitQ 的量化界不会自动覆盖这层误差；固定前缀、随机抽样、自适应停止还需要区分。本审阅只查原始论文并推导公式，未读取新的 Cohere 效果，未训练、实现新检索或计时。

## 1. 最直接的现有先例

[RaBitQ-SSD / Split-RaBitQ（2026-10-02）](https://arxiv.org/html/2610.02652v1#S3)的式 (2) 已使用长度 m 的二进制前缀，将部分内积乘 D/m，且分母保留完整码预先计算的校准量。定理 3.1 给出该前缀估计器的无偏性和随 m 缩小而变宽的概率误差界。其附录 A.3 明确要求前缀坐标集合不依据随机旋转 P 选择；保证来自原生码与随机旋转的对称性，不是任意已冻结码上固定前缀的条件保证。

[扩展 RaBitQ（2024）§4.2](https://arxiv.org/html/2409.09913v1#S4.SS2)还讨论先读所有维度的最高位、必要时再读低位。这与只读部分维度是不同的渐进计算方式。因此“只计算部分码，再细化”不能单独作为新颖性主张。

## 2. 冻结全码后，新的随机维度抽样给出条件无偏估计

统一写完整理想码分数为

\[
f=C-\alpha S,\quad S=\sum_{i=1}^D t_i,\quad t_i=v_i s_i,\quad s_i\in\{-1,+1\}.
\]

v 可以是旋转后的 query，或固定中心下的 query−center；C 和 α 必须是完整码的固定量。条件在全部 v、s、C、α 上，对坐标均匀无放回抽取 m 个，且抽样随机性独立于这些量：

\[
\widehat S_m=\frac Dm\sum_{i\in I_m}t_i,\qquad
\widehat f_m=C-\alpha\widehat S_m.
\]

每一维被纳入的概率为 m/D，因此 E[Ŝ_m|v,s]=S，E[f̂_m|v,s,C,α]=f。这个结论不要求各坐标独立，也不要求码仍是原生 sign 码；已学习的固定码同样适用。它只保证近似完整码分数，不保证近似真实距离。

注意只放大内积贡献，不将整个包含 C 的部分分数乘 D/m。若 α 原本含 rᵀs 或完整码校准分母，必须继续使用已存的完整量。用同一部分坐标重新估计分母后相除，一般不再无偏。

对 D≥2，令 V=(1/(D−1))Σ(t_i−S/D)²，则

\[
\operatorname{Var}(\widehat S_m\mid v,s)
=\frac{D^2}{m}\left(1-\frac mD\right)V,
\qquad
V=\frac{\|v\|_2^2-S^2/D}{D-1}
\le\frac{\|v\|_2^2}{D-1}.
\]

分数方差再乘 α²。m=D 时误差精确为零；D=1 直接读取唯一维度。样本方差不能不加修正就冒充高置信上界。

固定前缀不具有这个条件无偏性。例如 t=(1,1,−1,−1)，完整 S=0，前两维线性外推却为 4。即使码先经过随机旋转，对一个已经固定的索引和任意 query，也不能把“对旋转取期望无偏”改说成“这个固定前缀必然可靠”。

### 保留完整中心校正与抽样残差，是不同的估计器

对图中心 c，写完整分数 f=C−α(q−c)ᵀs=A_full−αqᵀs，其中 A_full=C+αcᵀs。保留 A_full 而仅对 qᵀs 外推是一个合法估计器，但抽样噪声来自 q；它不能利用 q 与 c 的逐坐标相消。

令 ρ=D/m，q_prefix·s=Σ_{i∈I}q_i s_i，c_prefix·s 同理。残差版本为

\[
\widehat f_{res}=C-\alpha\rho\sum_{i\in I}(q-c)_i s_i
=A_m-\alpha\rho\,q_{prefix}^Ts,
\]

\[
A_m=A_{full}+\alpha(\rho\,c_{prefix}^Ts-c^Ts).
\]

若定义 B=−2α、h_full=(cᵀs)/2、h_prefix=(c_prefixᵀs)/2，则同式为 A_m=A_full+B(h_full−ρh_prefix)。这是精确代数。固定前缀和检查点时，可在建库阶段存每阶段/每边的校正量；随机改变维度集合时，校正也必须对应实际集合，不能复用另一前缀的量。

精确抽样方差中，令 P_s=I−ssᵀ/D，可写为

\[
\operatorname{Var}(\widehat f(v))=
\frac{\alpha^2D^2(1-m/D)}{m(D-1)}\|P_sv\|_2^2.
\]

因此残差版本降低方差，当且仅当 ||P_s(q−c)||²≤||P_s q||²。其上界随 ||q−c||² 控制，但改善不是普遍保证：若 q 平行 s，直接 q 版本的抽样方差已经为零，减去非平行的 c 反而可能增加方差。以上属于常见控制变量思想的具体化，不声称本身新颖。

生产实现若累积的是 0/1 码 LUT 而非 q_i s_i，必须同时追踪 qᵀs=2qᵀb−Σq_i 中的 query 补偿，以及 LUT 的量化零点/尺度。不能把概念上的 A_m 校正直接加到现有 fadd，却漏掉前缀改变后的 query 常数项。一次额外校正的存储、读带宽和算术成本也应单独计量。

## 3. 常数明确、可以计算的抽样置信区间

若 a≤t_i≤b，则对固定 m，采用 [Bardenet–Maillard 的 Hoeffding–Serfling 界，Corollary 2.5](https://arxiv.org/pdf/1309.4029) 两侧合并，有

\[
\Pr\{|\widehat f_m-f|>r_s(m,\eta)\}\le\eta,
\]

\[
r_s=|\alpha|D(b-a)
\sqrt{\frac{\rho_m\log(2/\eta)}{2m}},\qquad
\rho_m=\begin{cases}
1-(m-1)/D,&m\le D/2,\\
(1-m/D)(1+1/m),&m>D/2.
\end{cases}
\]

只用已知 query 分量即可选择 a=−||v||∞、b=||v||∞，无需预先读取所有符号码。m=D 时 ρ=0。该界有明确常数，但可能太宽，尤其在候选很多、要求整条查询的失败概率很小时；“有理论界”不意味着能很早停止。

还有不需要随机性或概率预算的界。已计算部分和 A=Σ_{i∈I}v_i s_i，剩余质量 T=Σ_{i∉I}|v_i|，则

\[
S\in[A-T,A+T],\quad f\in[C-\alpha A-|\alpha|T,\ C-\alpha A+|\alpha|T].
\]

若只保存剩余二范数，可用 T≤√(D−m)||v_remaining||₂，通常更宽。这个区间围绕已观察部分和，而非强行围绕 D/m 外推中心；其有效性不受自适应停止影响。

## 4. 怎样与原始 RaBitQ 的误差组合

[原始 RaBitQ 定理 3.2](https://arxiv.org/html/2405.12497#S3.SS2.SSS2)的保证依赖其随机码构造、固定数据/query 与校准估计器。它不是对任意 learned code、任意数据依赖的前缀或任意结构化旋转自动成立的界。原论文和 Split-RaBitQ 定理中的常数不能随意取 1，也不能将经验 ε 参数直接解释成指定的失败概率。

若另有已正确建立的量化界 P(|f−d_true|>r_q)≤η_q，而新的抽样界失败概率为 η_s，则

\[
\Pr\{|\widehat f_m-d_{true}|>r_s+r_q\}\le\eta_s+\eta_q.
\]

这是三角不等式与 union bound，不需要两种误差独立。查询量化、FP32/LUT 与常数因子的执行误差还需加入经证明的界 ξ，或直接把被近似对象定义成实际完整 kernel 的输出。重新学习符号码后，新的抽样界仍成立，但原生 RaBitQ 的 r_q 需要重新证明、使用有效的确定性重建误差界，或不再作真实距离保证。

若严格满足原生 Haar 模型，可从其几何分解获得可计算的替代阈值：对单位数据和 query，a=⟨ō,o⟩，完整内积误差等于 sqrt(1−β²)·sqrt(1−a²)/a·Z，其中 Z 是 D−1 维单位球面的一个坐标。D≥3 时 Z² 服从 Beta(1/2,(D−2)/2)，可用其分位数替换未指定常数的渐近尾界，并保守地去掉 sqrt(1−β²)≤1。该结论仍只覆盖对应随机模型；生产快速旋转、有限精度和学习后的码不能直接套用。

## 5. 自适应停止和图搜索选择需要额外置信控制

固定 m 的无偏不等于停止时无偏。例：两个总体值 (+1,−1)，随机先读一个；若读到 +1 就停止并输出外推值 2，否则读全并输出 0。完整和为 0，但停止后的估计期望为 1。

可实现的保守做法是预先固定 L 个检查点，在第 l 次检查使用失败预算 η_l，满足 Ση_l≤η。对同一随机排列的这些前缀同时成立的区间允许自适应停止；无需假设各次检查独立。若允许任意 m，可用 η_m=η/[m(m+1)] 等可求和预算。由区间决定停止仍不恢复停止估计器的无偏性。

候选同样是多重比较。若对固定候选宇宙的每条码同时保证区间，可 union bound；若图的下一候选依赖此前分数，则不能只引用单个固定候选的边际界。另一个可实现方案是先选择当前候选，再使用独立的新抽样随机性，对每个候选/检查点按预算分配条件失败概率。全查询预算为 η，最多 M 次候选检查、每次 L 个阶段时，可保守使用 η/(ML)。若共用同一随机排列和 FastScan 批次，不能未经证明就把已适应选择的候选视为新的独立抽样。

原生量化概率界也有相应的选择问题：graph 或 query 若根据同一随机码设计，需验证其条件或在事先固定的更大对象集合上给出同时保证。所谓逐候选“99%可靠”不是整条搜索“99%可靠”。

## 6. 对当前 Symphony 更直接的安全实现目标

可以先以“保持完整 kernel 的桶决策”为目标，无需声称恢复真实距离。实际 FastScan 若表示成固定因素加各 LUT 查表项之和，可在读完部分 LUT 组后，用每个未读组的最小/最大合法表值界定剩余整数累加和，再经过原完整分数的固定尺度及有向舍入计算区间。它对固定前缀、学习码与自适应停止均可有效，但区间可能很宽。

具体地，若完整整数累加器 J=Σ_{g=1}^G L_g(code_g)，已经算出 J_seen，则

\[
J\in[J_{seen}+\sum_{g\,unread}\min_kL_g(k),\quad
      J_{seen}+\sum_{g\,unread}\max_kL_g(k)].
\]

未读表的最小/最大值可按预定阶段预先累计。必须先确认累加器不发生环绕/饱和等破坏此和式的行为，再用完整 kernel 原有因素和实际舍入映射两个端点；尺度为负时交换端点。若改用均匀随机抽 LUT 组，完全相同的无放回公式可把 D 替换为 G、t_i 替换为组贡献；这不依赖 Haar 旋转，但仍要求抽样相对固定总体独立并处理候选/停止的自适应选择。

若整个最终分数区间都映射到同一个真实 FP32 locate 桶，就可以认证该 lane 的完整码桶号；否则继续读。比较候选次序时可以使用不相交区间。界必须覆盖实际 FMA/舍入，判定必须使用真实机器跃迁，不能用名义 bucket_index×width 代替。

图搜索中不能因某候选不像最终 Top10 就直接删掉它，它可能是后续近邻的桥接节点。保留完整桶、重复 token、LIFO、visited 和停止语义，才有可能逐步证明路径与完整码基线一致。即使数学上少算，随机维度读取、检查区间、每批 32 lane 的歧义比例和 SIMD 布局仍决定实际成本，不能从 m/D 直接推出 QPS 加速倍数。

因此可行方向是“部分读码→有效区间→能确定决策则停，否则补全”。现有 Split-RaBitQ 已直接覆盖线性前缀外推；本项目若有贡献，应来自适合图遍历和现有 FastScan 布局的具体停止证书与实测成本，而不是重复已有无偏公式。
