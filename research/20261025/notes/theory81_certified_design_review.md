# 阶段 81 数学审阅：预算符号码的可验证下界与路径证书边界

本审阅给出可严格检查的经验优化证书，未训练 Cohere 码、未调用 LP/MIP 求解器，也未运行检索或 QPS 测试。LP 对偶、hinge 上界、约束筛除与一般路径耦合都是标准工具；潜在研究贡献须由本编码族的算法、实际决策语义、可复现收益和与已有工作的区别共同建立。

## 1. 固定阈值产生线性二进制目标的条件

设残差 r=v−c≠0，δ=q−c，R=||r||²，s∈{−1,+1}^d，u=rᵀs>0。令 ν=(||c||²−||v||²)/2、C=1−qᵀc+R/2+ν。理想径向分数为

\[
f_s=C-\frac{R\delta^Ts}{r^Ts}.
\]

对不依赖待优化码的阈值 t，a_t=(C−t)r−Rδ，故 f_s−t=a_tᵀs/u。由于 u>0，五种关系 <、≤、=、≥、> 的符号逐一等价；不能忽略阈值相等的处理，也不能将不正分母代入此等价式。

固定 s₀=sign(r)，零坐标按生产约定取 −1，u₀=||r||₁>0。令 s=s₀⊙(1−2z)，z∈{0,1}^d，则 u=u₀−2Σ|r_k|z_k。对 1≤τ<∞，Hamming 预算和尺度比约束精确变成

\[
\sum_kz_k\le B,\qquad m^Tz\le W=\frac{1-1/\tau}{2}u_0,
\qquad m_k=|r_k|.
\]

第二项保证 u≥u₀/τ>0。这是最终码的可行集合，不等于旧贪心坐标下降的可达轨迹。τ=1 时仍可能允许零残差坐标翻转；Hamming 预算仍须计数这些坐标。

对真实非零阈值差 D_j−t_j，预先固定 y_j=sign(D_j−t_j)、γ_j>0、κ_j=γ_j u₀。定义

\[
\ell_j(z)=\left[1-\frac{y_ja_j^T[s_0\odot(1-2z)]}{\kappa_j}\right]_+
=[b_j+A_jz]_+,
\]

\[
b_j=1-y_ja_j^Ts_0/\kappa_j,\qquad
A_{jk}=2y_ja_{jk}s_{0k}/\kappa_j.
\]

逐点有 1{y_j(f_s−t_j)≤0}≤ℓ_j；估计分数落在阈值上按保守错误处理。真实 D_j=t_j 必须独立标记，不给它虚构正负标签。ℓ_j=0 蕴含有符号理想分数 margin≥γ_j；反方向 margin≥τγ_j 足以保证 ℓ_j=0，但 margin≥γ_j 一般不够。γ 必须预先固定，不随候选码或验证效果选择。

两个同时学习的候选互相比大小时，交叉相乘的分子一般含 u_i u_j、(δ_iᵀs_i)u_j，成为二次二进制式。这里的线性结论只针对单码的固定阈值。

## 2. 可独立核查的 Lagrange 证书

考虑非负固定权重 w_j、m_k，以及 B,W≥0：

\[
F(z)=\sum_jw_j[b_j+A_jz]_+,\quad
\mathcal P=\{z\in[0,1]^d:\mathbf1^Tz\le B,m^Tz\le W\}.
\]

任取 0≤λ_j≤w_j，μ,η≥0，定义

\[
d_k=(A^T\lambda)_k+\mu+\eta m_k,\qquad
L=\lambda^Tb-\mu B-\eta W+\sum_k\min(0,d_k).
\]

则对所有 z∈P，F(z)≥L，因而 L≤v_LP≤v_IP≤U，其中 U=F(ẑ)，ẑ 是任何经核实可行的整数码。

证明：w_j[x]_+≥λ_jx 对所有实数 x 成立。对可行 z 加上两个非正预算项得到

\[
F(z)\ge\lambda^Tb-\mu B-\eta W+d^Tz
\ge\lambda^Tb-\mu B-\eta W+\sum_k\min(0,d_k).
\]

因此 U−L 是整数经验目标次优差的有效上界。由于此处 LP 非空且有有限最优值，标准 LP 强对偶也给出对这些乘子取上确界等于 v_LP；本次验证仅检验任意合法乘子的弱对偶式，并未求解 LP。

浮点求解器可以仅作为候选乘子来源：将候选明确转换为有理数，验证或投影到 0≤λ≤w、μ,η≥0，再用 Fraction 重新计算 L，无需相信浮点求解器的最优状态或容差。证书的系数定义必须冻结。把浮点系数解释为精确二进制有理数只认证该数值经验目标，不能自动认证真实几何或生产 FP32/LUT。

若另有严格逐行系数误差 |Δb_j|+Σ_k|ΔA_jk|≤ε_j，hinge 的 1-Lipschitz 性给出 |F_true(z)−F_frozen(z)|≤Σε_jw_j。可在下界减去这项后认证相应系数模型；它仍不替代对生产执行路径、浮点舍入和非线性桶映射的误差控制。

## 3. 安全删坐标：同一份原始证书与严格不等号

用同一组乘子和未经截断的 L，强制 z_k=1 或 0 的下界分别为

\[
L_{k,1}=L+\max(0,d_k),\qquad
L_{k,0}=L+\max(0,-d_k).
\]

这是把箱约束最小化项 min(0,d_k) 分别替换为 d_k 或 0。若 L_{k,b}>U，则可排除该分支，且不丢任何 F(z)≤U 的整数可行解。只有等号时不能声称该位被所有最优解固定；若仅寻找严格优于已有解的码，可以另行说明等号分支不含严格改善，但这与保留所有最优码不同。预算直接导致不可行的分支可另作可行性筛除。

不同证书可取 max_i L_{k,b}^{(i)}，不能把某证书的全局 L 与另一证书的 d_k 拼接。可以在已正确算出条件下界后取 max(0,L_{k,b})，不能先截断全局 L 再加坐标增量。

明确反例：d=1，F(z)=[2−z]_+，B=W=m=1，整数最优 z=1、U=1。取 λ=0、μ=6、η=0，raw L=−6、d₁=6，正确 L₁,₁=0。若先取 max(0,L)，会误得 6>1，删掉真正最优解。另一证书 λ=1、μ=η=0 的 L=1；与前一个 d₁=6 混合会更错误地给出 7。脚本显式重现了两种错误。

## 4. LP 下界可以无信息，不能保证求解容易

令 d=2，B=W=1，m=(1,1)，

\[
F(z)=|z_1-1/2|+|z_2-1/2|.
\]

四项非负 hinge 即可表达这个目标。全部整数可行码 (0,0)、(1,0)、(0,1) 的目标为 1，而 LP 可行点 (1/2,1/2) 的目标为 0。因此 LP 对偶最优值也可能为 0；不能承诺乘法近似比或小整数 gap。该反例中每个坐标单独置 1 都可行，简单预算预筛不能消除此 gap。

小规模 phase81 的合理用途是冻结同一训练目标和翻转域后，同时报告原码、启发式可行码 U、精确检查的 L、安全筛除比例及剩余 U−L。若 gap 很大，应诚实报告未能认证优化质量，不能将求解器超时等同于目标无效。若 gap 很小但验证决策变差，才有证据把失败重点转向目标和分布，而不是继续归因于优化没收敛。

## 5. 首次路径分歧：能认证什么

设两个确定性搜索运行使用相同 query、入口、图、配置和所有不由码改变的状态。沿完整 native 事件流构造 learned 影子队列：每次展开必须强制沿 native 中心，但所有此前 proposal 使用 learned 分数进入 learned 队列，保留 visited、重复 token、同桶 LIFO 和实际停止语义。

在第一次 next-ID/stop 分歧之前，真实 learned 与此影子运行已经访问同样的中心并产生同样的 proposal，因而 learned 影子状态等于实际 learned 状态。由归纳可精确识别第一次动作分歧。**不能**只把下一次候选换分、却保留 native 队列的旧分数；也不能在首次分歧后把强制 native 的影子路径当成真实 learned 路径。

对当前桶实现，一个充分条件是：沿 native 路径，每个会影响队列的 proposal 的实际桶号不变，同时所有独立的停止/容量/并列条件保持一致。则队列 token 顺序、visited 清理、展开和结果不变。连续分数完全相等不是必要条件。反过来，首次路径分歧必有某个此前状态相关操作发生变化，但首次桶号变化通常早于首次路径变化。

将“先前动作相同且第 t 个动作首次不同”记为 E_t，则这些事件两两不交，P(Δ)=Σ_tP(E_t)。若已为每个 E_t 找到逐点覆盖它的非负损失 g_t，则

\[
\Pr(\Delta)\le\mathbb E\min(1,\sum_tg_t)\le\sum_t\mathbb E g_t.
\]

这不要求独立性，但要求覆盖全部可能改变动作的比较、并列、重复项和停止事件。固定阈值 hinge 只有在其阈值和标签确实覆盖该实际动作时才能作为 g_t；真实桶号是经过验证的 FP32 映射，不能直接用理想实数桶边界代替。

此外，真实精确距离标签对应“对真值的错误”，不等于“偏离已有 native 决策”。若两个规则都与同一无歧义真值比较，才能逐点使用 disagreement(new,native)≤error(new,true)+error(native,true)；仅上界 new 的真值错误不够。一个更正确的排序器完全可能故意偏离有误的 native 路径。

每 query 的任一动作失误需要累计损失 Σ_tℓ_t，而不是除以比较数后的平均损失。平均比较错误率只界定抽到一个比较时的风险；不能不补回比较次数就把它称为整条路径风险。类别平衡权重同样改变了风险对象：若目标权重满足 w_j≥c p_j，才有自然风险 Σp_j error_j≤F/c；对某些必要比较给零权重一般没有这种保证。

## 6. Recall 与 QPS 的严格边界

若没有分歧就保证输出一致，且每 query recall∈[0,1]，则 |E recall_new−E recall_native|≤P(Δ)。它既不保证改善方向，也可能完全无用。阶段80已有 999/1000 条 query 首次动作分歧，而实际 recall 差远小于该界；一般 union bound 不是性能突破。

只有对一个明确、有统一范围 [C_min,C_max] 且相同路径成本相同的抽象工作量，才能类似得到 |E C_new−E C_native|≤(C_max−C_min)P(Δ)。实际耗时不满足“路径相同则成本相同”的自动假设：评分额外开销、内存布局、缓存和编译差异都可改变耗时。即使全部路径相同，也可以通过人为延迟每次评分使 QPS 任意下降。不能把路径证书转写成真实 QPS 保证。

反之，大量局部变化可以不改变最终 Top10；一个关键早期桥接边变化也可能显著损害 recall。优化理想经验 hinge 的全局最优码，仍可能没有实际召回或吞吐收益。

## 7. phase81 训练前仍须冻结的内容

当前数据可行性协议只按 ID/访问元数据冻结 4096 条数据库 query 的 3072/1024 拆分与 20 个中心。step≤8 早于 STOP_MIN=10/Top10 满足实际停止前提，不能据此称为实际停止决策训练。它适合研究另行冻结的桶/局部比较目标；若研究停止必须单独定义对应状态采样。

建议在读取训练效果前冻结阈值来源、query/state/比较权重、γ 的固定公式、真实零 margin 和生产并列规则、预算、优化时限、原码可行保底、校验方式和留出验收门槛。类别平衡只能使用训练计数，缺失类别须有明确策略；平衡错误率与自然 query 等权错误率须分别报告。真实训练尚未开始，不在此选取新 γ 或调阈值。

共享数据库、共享图和按到达中心条件化的查询划分不是独立外部查询盲测。与现有方法的公平比较须使用相同拆分和候选域重新拟合，不能把可能接触过这些数据库 query 的旧模型当作同条件留出对照。

## 8. 精确穷举记录与已有工作

脚本 `scripts/theoretical81_dual_certificate_check.py` 只使用 Python 标准库 Fraction 与固定 seed8102。维数 1..8，每维 8 个随机有理问题；每题 5 组合法候选乘子，另加 4 个边界 fixture。它枚举所有整数码后逐点核对上下界及每个实际分支，只有严格 >U 才筛除。

结果 `results/theoretical81_dual_certificate_check.json` 全部通过：68 个问题、4090 个枚举码、994 个可行码、324 份证书、4942 次全局下界检查、33383 次条件下界检查；81 个分支被严格筛除，其中 13 个原本有可行码，且没有丢失任何目标≤U 的码。152 个等于 U 的分支保留。分支计数单位是 certificate×coordinate×value 次数，不是去重坐标数或实际优化收益。7 类非法乘子/非精确数值输入均 fail closed；未声称覆盖输入验证器的全部拒绝分支。独立 fixture 验证 U=L=1 的非零最优、零预算/零权重、错误截断/混证书和 LP 整数 gap。枚举只是小维数学验证，不是对真实 768 维问题求得最优码。

这些证明使用标准 Lagrange/LP 对偶与逐点 hinge 上界；对偶背景见 [Boyd 与 Vandenberghe 的官方教材](https://web.stanford.edu/~boyd/cvxbook/)。[RPQ 原论文](https://arxiv.org/abs/2311.18724)已经使用图的路由特征学习 PQ，因此 routing-aware 不能作为本工作独有概念。[2026 年比较决策论文](https://arxiv.org/abs/2609.09854)已研究 margin、相关残差、冻结候选动作耦合与留出证书，因此一般决策风险和路径耦合也不能作为本工作独有理论。

值得继续检验的具体组合是：保持现有径向一比特码和扫描接口，在固定预算内直接优化实际相关阈值，再给出可独立检查的经验优化 gap 与筛位证书，并在新路径、真实 FP32 与独立查询上检验收益。这是研究路线，尚不是新颖性结论或已实现性能突破。
