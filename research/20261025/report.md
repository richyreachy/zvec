## 测试条件

- CPU：Intel Xeon 6982P-C，8 个物理核 / 16 个逻辑 CPU；固定亲和性 `0,2,4,6,8,10,12,14`。内存约 30 GiB，无 swap。
- Cohere：1M × 768D，cosine；GIST：1M × 960D，平方 L2。每个数据集 1,000 条查询，Recall@10 按返回 ID 与给定 Top-10 GT 的交集计算。
- 初始 HNSW 图固定 M=50、efConstruction=500。量化图最多 32 邻居。改进中的补边作用于内存缓存的派生图，不改变源 HNSW 索引。
- 每次调用处理 1 条查询；1/8 查询线程；完整预热后每点连续测量 3 秒。QPS 是端到端搜索吞吐；建图、打开索引和缓存编码不计入查询时间。
- 最终改进配置各 5 轮；Cohere 原生前后合计 5 轮，GIST 原生前后合计 7 轮。计时阶段不并行编译或运行其他实验。
- 原始命令、逐查询命中数、返回 ID/FP32 分数、QPS、延迟和 RSS 均保留。源数据与历史索引未覆盖。

## 最终参数与算法

| 数据集 / 目标 | 候选结构 | margin | patience | 最大展开数 | 其他变化 |
|---|---|---:|---:|---:|---|
| Cohere / 95% | 分桶，桶宽=0.002×入口距离 | .07 | 0 | 沿用原上下文扫描预算 | 原图、原旋转、FP32 中心 |
| Cohere / 99% | 同上 | .12 | 96 | 512 | 补齐不足 32 的邻接槽；768D 正交变换 |
| GIST / 95% | 同上 | .14 | 0 | 256 | 补边；SQ8 中心；重构中心重编码；选择性 FP32 核算 |
| GIST / 99% | 同上 | .15 | 256 | 1536 | 同上 |

候选按量化估计距离分桶，两级位图定位最小非空桶，桶内 LIFO。保留多中心候选估计，实际展开时去重。停止判断比较桶下沿与当前**精确**第 K 距离，并结合 patience / 最大展开数。

**仍然有 refinement。** Cohere 对展开节点计算 FP32 距离；GIST 先读取 SQ8 中心，只有结果距离下界可能进入 Top-K 时才访问原 FP32 向量。没有进行 FP32 核算的节点仍然扫描邻居，避免把不可能进入结果的桥梁节点错误地排除出导航。

## 数理依据

完整推导见 [理论草稿](theory_draft.md) 与 [原估计器几何审计](geometry_notes.md)。已实现的关键性质是：

1. **重构中心一致性。** 以重构中心 a 编码邻居残差 r=v-a，范数校正使 rᵀe=0。理想 L2 估计满足 `d_hat(q,v)-||q-v||² = -2(q-v)ᵀe`，因此 q=v 时理想误差仍为零。只压缩中心却保留原中心残差编码，会引入额外共同偏差。
2. **选择性核算的结果安全性。** 离线保存 ε≥||u-a||。由三角不等式，`||q-u||² ≥ max(0, sqrt(||q-a||²)-ε)²`。若有效下界已大于当前精确第 K 距离，则无需为最终结果读取该节点 FP32；该结论仅针对已经展开的集合。
3. **浮点误差处理。** 实际核直接累加平方差。以 γ=(D+4)·2^-24 / (1-(D+4)·2^-24) 约束舍入后，下界采用 `(1-γ)·max(0,sqrt(s_fp/(1+γ))-ε)²`，另加下溢补偿并向安全方向舍入。适用前提及实现细节见理论草稿；没有把它泛化到任意距离核。
4. **桶内排序误差。** 普通桶在估计分数域引入至多一个桶宽的排序松弛（另计舍入）；它不提供全局图 Recall 保证。

**没有证明任意 HNSW 图上的全局召回率保证。** 当前停止规则仍是经数据校准的启发式；可导航图条件引理不能直接套用到未经验证的裁剪图。

## 正确性检查与失败实验

- 当前默认代码路径重编译后，28 项原生 Symphony 单元测试通过；原仓库未修改。
- 桶队列性质检查 266,534 次通过；唯一 beam 检查 296,020 次通过。
- FP16 / SQ8 最终下界检查各 18,000 组通过，包含 q=u、非常接近的点、非 SIMD 整数倍维度与不同数值尺度。
- 原生、投影、Paley 几何检查各 192 项通过，均显式启用断言；重构中心编码检查另保存日志。
- GIST 最终审计逐节点核算真实 FP32 距离，未发现下界越界或错误排除可进入 Top-K 的节点。2,000 组审计查询与计时版本的 Top-K 距离多重集一致。
- 收紧下界前后的结果距离也逐查询一致；少量 ID 集合或顺序差异来自完全相等的 FP32 距离及结果堆 tie 行为，ID-based recall 仍按原定义如实计算。

失败/非主线方案也已保留：精确邻居 oracle 未稳定改善原生 beam 召回；线性去重 beam 的额外工作抵消收益；几何常数偏置与 512/384D 投影没有稳定优势；无界二叉堆未胜过紧凑队列；Cohere 阈值直接迁移 GIST 失败。详见 [研究日志](research.md) 与 [完整筛选表](screen_results.md)。

GIST 最后一个版本还包含 SQ8 距离核的多累加器实现，它是实现层面的收益，不能全部归为新理论；单独对照保存在 screen20。

## 论文层面的判断

性能门槛与数学局部性质已经有实测和推导支持，但**现在仍不能直接声称原创论文贡献**：

- [Distance Adaptive Beam Search](https://arxiv.org/abs/2505.15636)、[DARTH](https://arxiv.org/abs/2505.19001) 和 [Ada-ef](https://arxiv.org/abs/2512.06636) 已研究自适应停止/搜索预算。
- [BBC](https://arxiv.org/abs/2604.01960) 已研究 ANN 结果收集中的分桶；不能把“使用桶队列”本身当作创新。
- [SymphonyQG](https://arxiv.org/abs/2411.12229) 已有批次对齐图优化；[RaBitQ-Library 当前实现](https://vectordb-ntu.github.io/RaBitQ-Library/index/qg/) 也支持可选 4/8-bit 顶点存储。

较值得继续论文化的部分，是中心压缩、邻居残差重编码、局部结果精确性与候选调度的联合分析。仍需对照这些方法的当前实现、扩大到独立查询及更多数据集/规模/Top-K，并完成参数敏感性和更完整的消融。本文只确认当前代码与两个固定 1M 数据集、Top-10、静态无过滤查询的性能进展。
